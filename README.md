# 🚍 SafeRoute – Smart Public Transport Safety System

SafeRoute is an innovative safety solution designed to enhance security in public transport systems, with a special focus on women’s safety. The system provides real-time tracking and emergency alert features to ensure quick response during unsafe situations.

## 🔍 Problem Statement

Public transport users, especially women, often face safety concerns due to lack of real-time monitoring and delayed emergency response systems.

## 💡 Solution

SafeRoute addresses this issue by integrating live location tracking and an SOS-based emergency alert system that instantly notifies trusted contacts.

## ⚙️ Features

* 📍 Real-time location tracking
* 🚨 One-click SOS emergency alert
* 📲 Instant notification with live location
* 🌐 User-friendly web interface
* 🔄 Continuous journey monitoring

## 🛠️ Technologies Used

* Frontend: HTML, CSS, JavaScript
* Backend: Python (Flask)
* APIs: Geolocation API
* Other Tools: VS Code, GitHub

## 🎬 How It Works

1. User opens the SafeRoute interface
2. System tracks live location continuously
3. In case of emergency, user presses the SOS button
4. Alert message with live location is sent instantly

## 🎯 Impact

SafeRoute aims to make public transportation safer and more reliable by enabling quick emergency response and real-time monitoring.
